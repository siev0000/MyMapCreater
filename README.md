# AA船内マップ制作（上層・中層・下層）

アポクリファ＝アーカイブ（AA）船内の三階層マップを、Notionの現行設定と照合しながらGitHubで**大枠から段階的に設計**するプロジェクト。

## 最初に読む制作ルール

**[AA施設・街区マップ制作統一ルール v1](./docs/aa-map-production-workflow-v1.md)**

基本順序：**全体骨格 → 地区・主要施設の外形 → 道路・隔壁 → 内部の大区画 → 受付・作戦室などの細部 → 総合検証 → ユーザー承認 → Notionへ反映**。

**Notionが現行の正式設定の正本。GitHubの `*-layout-draft.json` は制作途中の配置案**で、完成承認まではNotionへ追記しない。施設の細かい説明や内部区画は、通常マップでは出さず、対象施設を選択して確認する。

## 画面

- [マップ表示（index.html）](./index.html) — 上層・中層・下層の表示、Notion比較用の配置とGitHub再配置案の切り替え
- [配置エディター（editor.html）](./editor.html) — 施設と道路の下書き調整

## データ

- `data/upper.json`、`data/middle.json`、`data/lower.json`：Notion記載の配置を比較する基準データ（制作中は変更しない）。
- `data/upper-layout-draft.json`、`data/middle-layout-draft.json`、`data/lower-layout-draft.json`：GitHubでの段階的な制作案。
- `docs/`：制作ルール、検証メモ、変更・確認記録。

## 現在の方針

- 三階層とも中央ターミナル塔は直径500mを暫定維持（Notion初期寸法）。
- 中層：リンクターミナルの内部にレジストリンク・ドームを配置する案。コアシェルタウン、リファインバレー、アルキメリア装備開発ラボは同じ連続した生活圏へ。
- 上層：共同管理・研究区と認証区画の接続を維持し、認証門と道路の位置ずれは再検証。
- 下層：ラストハブの生活動線と再処理・危険物・上層専用出撃区を分離する。
- **既存の細かい区画描画は検討用。大枠の段階確定を飛ばして正式設定として扱わない。**

## GitHub Pages

Settings → Pages で、デプロイ元をブランチの `main`・`/(root)` に設定すると `index.html` をWeb上で表示できる。公開範囲は利用前に確認する。
