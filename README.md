# AA船内マップ制作（上層・中層・下層）

アポクリファ＝アーカイブ（AA）船内の三階層マップを、Notionの現行設定と照合しながらGitHubで**大枠から段階的に設計**するプロジェクト。

## 最初に読む制作ルール

**[AA施設・街区マップ制作統一ルール v1](./docs/aa-map-production-workflow-v1.md)**

基本順序：**全体骨格 → 地区・主要施設の外形 → 道路・隔壁 → 内部の大区画 → 受付・作戦室などの細部 → 総合検証 → ユーザー承認 → Notionへ反映**。

**Notionが現行の正式設定の正本。GitHubの `*-layout-draft.json` は制作途中の配置案**で、完成承認まではNotionへ追記しない。施設の細かい説明や内部区画は、通常マップでは出さず、対象施設を選択して確認する。

## 画面

- **[中層 A・B・C 配置を地図で比較（overview.html）](./overview.html)** — 上層・中層・下層を切り替え。中層では「外周加工」「中央加工」「併用」の3案を同じ船体図で視覚比較する。
- **[中層の残タスク](./docs/aa-middle-completion-checklist-v1.md)** — 次に確定する地区の大枠、道路接続、施設内区画、完成検証を整理。

- [マップ表示（index.html）](./index.html) — 上層・中層・下層の現行制作案を表示。施設を選択すると用途を案内
- [配置エディター（editor.html）](./editor.html) — 施設と道路の下書き調整

## データ

- `data/upper.json`、`data/middle.json`、`data/lower.json`：現行設定を照合するために内部保持する参照データ（通常の画面比較からは除外）。
- `data/upper-layout-draft.json`、`data/middle-layout-draft.json`、`data/lower-layout-draft.json`：GitHubでの段階的な制作案。
- `docs/`：制作ルール、検証メモ、変更・確認記録。

## 中層マップの3段階表示（区画 → 施設 → 施設内部）

- **初期表示**：大枠（区画）と中枠（施設）の**枠線を同時に表示**。文字は大枠の区画名のみ。
- **大枠を選択**：選択した区画名を隠し、区画内にある中枠（施設）の**名前を表示**。大枠・中枠の線は残す。
- **中枠を選択**：選択した施設の枠線と施設名を隠し、その施設の**小枠（施設内部）と各小枠名**を表示。他の中枠の線は残す。
- **小枠を選択**：同じ施設の小枠を表示したまま、選択対象を強調。小枠の説明はポップアップで確認。
- **数量**：船首・船尾の4大区画、中枠18件、小枠36件（小枠は部屋数・設備数の確定ではない）。既存のアルキメリアラボ・船尾実用技術ラボの建物枠は重複作成しない。
- **ポップアップ**：説明を開いたまま地図を拡大・縮小、ドラッグ・ピンチ操作できる。背景操作を塞ぐ全画面マスクを廃止し、説明欄には×ボタンを設置。
- **柱**：主要・補助支柱は灰色の仮位置マーカー。構造計算による確定位置ではない。
- 中層の通常マップ・エディター・B案比較画面で同じ階層ロジックを採用。実ブラウザでの最終操作確認は継続。


## 中層の表示規格（船尾街区と道路）

- **船尾側の下位街区を地区として大きく表示**：船尾タウン側と工房・研究側を、それぞれ道路・広場・各工場を含む広い地区輪郭として表示。地区の広さは単一建築物の床面積ではない。
- **工場4件の位置・寸法は維持**：燃料160×120m、植物油100×80m、繊維・樹脂120×100m、植物素材140×100m（いずれも生産能力検証前の仮寸法）。
- **中層道路は細線表示**：紫の大型機幹線・橙の貨物幹線は細い二重線、一般道路と施設荷役支線は細い単線。地図の線の太さは実際の道路幅を表さない。
- 規格は中層の表示にのみ適用。上層・下層の道路表示や世界設定数値を変更しない。

## 現在の進行状況

- **中層B案を通常マップ・配置エディターへ反映済み**：船首の上位タウン＋ラボを維持。リンクターミナル船尾半周の下位タウン・ラボを**各約19.5万m²の広域混合街区**に拡張し、その中に寸法維持の小規模加工施設4棟を配置。各工場の荷役口は橙の専用貨物路へ接続する仮配置。
- 中層のアルボラを選択すると、森林・育苗・湿地・乾燥・調査・監視の6大区画を表示。個別監視所や研究室は未設計。
- 工場寸法は生産能力未確定のため**仮寸法**。中層の道路は見やすさ優先で**幹線を細い二重線、支線を細い一本線**で表示し、実際の道路幅数値はデータに残す。貨物路は橙色の専用仮ルート、紫の大型機通路は別系統。貨物リフト入口・隔壁・避難・環状路は未検証。
- 中層配置レビューは [B案を初期表示するマップ](./overview.html) から開ける。

## 現在の方針

- 三階層とも中央ターミナル塔は直径500mを暫定維持（Notion初期寸法）。
- 中層：ターミナル内にレジストリンク・ドーム。船首は上位タウン・ラボ、船尾半周は下位タウン・ラボ・加工施設の混合街区。階級間の待遇・通行制限は未決定。
- 上層：共同管理・研究区と認証区画の接続を維持し、認証門と道路の位置ずれは再検証。
- 下層：ラストハブの生活動線と再処理・危険物・上層専用出撃区を分離する。
- **既存の細かい区画描画は検討用。大枠の段階確定を飛ばして正式設定として扱わない。**
