# マップ制作メモ（memo/）

このフォルダは **MyMapCreater × 鬼武神ラセツ** の地図制作に関する記録を保管する場所です。

## ファイル

- [RASETSU_MAP_DESIGN_RULES.md](./RASETSU_MAP_DESIGN_RULES.md) — **現行の制作ルール（正本）**。マス数、縮尺、地図の親子構造、確定・未確定の扱い、作業前チェック、編集手順。
- [RASETSU_MAP_CHANGELOG.md](./RASETSU_MAP_CHANGELOG.md) — **変更履歴（正本）**。何をいつ変更し、なぜ決めたか、旧ルールとの差分と未解決事項。
- [汎用シーンJSON仕様](../rebuild/SCENE_FORMAT_v2.md) — エディターとシーンデータの技術仕様（`rebuild/` 内で引き続き管理）。

## 今後の運用

1. 制作・修正前にこのフォルダの **設計ルール** を読み、対象の最新シーンJSONとNotion設定を確認する。
2. 正本以外の旧ファイル・過去の会話だけから現行ルールを推測しない。
3. 作業完了後、**変更履歴** の冒頭へ変更日・対象・理由・確定/暫定・残課題・コミットを追記する。
4. 決定したルールが変わった場合は**設計ルール本文を更新**し、その理由と旧ルールを**履歴に残す**。
5. 世界観の地理設定そのものの正本はNotionの「鬼武神ラセツ > 地域・国家」。マップの仮図で世界設定を勝手に確定させない。
