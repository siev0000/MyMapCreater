GitHubに直接保存するための認証設定

GitHub Pagesにはログイン用サーバーがないため、ここでは期間・対象リポジトリを限定した Fine-grained personal access token を使用します。GitHubの通常ログイン連携とは異なります。

GitHubで Only select repositories → siev0000/MyMapCreater → Contents: Read and write を選び、期限を短めに設定してください。トークンをチャットやJSON、GitHubのファイルに貼り付けないでください。

Fine-grained token を作成　｜　保存先は data/upper-layout-draft.json など、各階層の配置案専用ファイルです。
