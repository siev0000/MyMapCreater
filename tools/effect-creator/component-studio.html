高度な設定（GLSLコード・項目定義）

p: 中心基準座標、t: 模様時間、q: 0〜1の進行。共通関数 ball / ring / light / charge / lfPlume / denseBurst 等を使用できます。既存部品から複製すると依存と固有パラメータも継承します。固有パラメータを関数本体から参照できます。

固有パラメータ定義

IDをGLSL内で変数として使用。最大16項目。型・初期値・範囲・単位を指定します。

登録はこのブラウザーに保存されます。GitHub共有はJSONを別途反映する必要があります。信頼できるGLSLのみ読み込んでください。

タイムライン

中央をドラッグで移動、左右の端をドラッグで開始・終了調整。離した時に反映します。空白をタップすると再生位置を変更できます。細かい調整は拡大または部品設定タブの数値入力で行えます。

部品を追加または選択してください。

座標は中心0、右+X、上+Y。開始と終了の座標を変えると移動します。弧の高さで放物線にできます。
