HTML / CSS / JS コードプレビュー

隔離フレーム内で再生。インラインSVG＋CSSアニメーション、または下記のCanvas描画関数から透過画像を出力できます。通常のHTML要素の画像化は未対応です。

画像出力は共通の幅・高さ・FPS・秒数・列数を使用します。SVGは内蔵図形と対応CSSに限定。Canvas例は renderFrame({canvas,ctx,time,duration,frame,fps}) で各コマを描画します。
