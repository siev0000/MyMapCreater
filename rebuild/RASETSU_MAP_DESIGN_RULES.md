# 鬼武神ラセツ｜マップ制作・設計ルール（現行）

> 最終整理：2026-11-23。**今後の鬼武神ラセツ地図作業では、この文書と関連するNotionの国家・地域正本を先に読み、現行のシーンJSONを取得してから編集する。**
>
> このファイルは **制作手順と技術上の基準** を記録する。架空世界の設定の正本はNotion「鬼武神ラセツ > 地域・国家」等とし、地図の仮配置を確定設定へ昇格させない。
>
> 変更履歴は [RASETSU_MAP_CHANGELOG.md](./RASETSU_MAP_CHANGELOG.md) へ。汎用マップJSON仕様は [SCENE_FORMAT_v2.md](./SCENE_FORMAT_v2.md) へ。

## 1. 確定事項：マス数と座標系

- 標準マップ：**1000×1000マス＝1,000,000マス**。ユーザーがブラウザーで試し、採用を承認した値。
- **1マス＝50 scene座標単位**。標準の `coordinateSystem.bounds` は `{minX:0,maxX:50000,minY:0,maxY:50000}`、`grid.spacing=50`。
- 表示用のグリッドと、オブジェクト編集時の `settings.editorGrid`（スナップ）は別設定。地図の実寸縮尺（m/マス）とも混同しない。
- 1000×1000は新規制作の**標準キャンバス**であり、すべての既存マップに強制適用しない。建物内部など、必要がない場合は少ないマスを使ってよい。
- 100万マス＝100万個の描画オブジェクトを意味しない。表示線は必要な範囲のみ描画し、一定の縮小時には非表示となる。ブラウザーの快適性はオブジェクト数・頂点数・実行環境にも依存する。
- 既存図形の座標・輪郭・サイズは、縮尺プリセットを選んだだけでは変更しない。新しいマス数にリサイズするときは複製・バックアップを取り、縦横比・位置関係を維持して変換する。

## 2. 確定事項：7階層の距離基準（`rasetsu-seven-level-v2`）

| 階層（tierId） | 1マスあたりの距離 | 1000×1000マスの地図全域 |
|---|---:|---:|
| `world`：世界地図 | 40,000m＝40km | 40,000×40,000km |
| `continent`：大陸地図 | 5,000m＝5km | 5,000×5,000km |
| `nation`：国家地図 | 500m | 500×500km |
| `region`：地方地図 | 100m | 100×100km |
| `town`：都市・町 | 50m | 50×50km |
| `district`：街区・敷地 | 10m | 10×10km |
| `interior`：建物内部 | 1m | 1×1km |

- 参照実装：`rebuild/map-scale-presets.js`。旧版 `rasetsu-seven-level-v1` より現行 `v2` を優先。
- シーンへの記録：`settings.mapScale={standardId,tierId,metersPerCell,coordinateUnitsPerCell,metersPerCoordinateUnit}`。
- 1座標単位の実距離は `metersPerCell/50` メートル。例：大陸マップは **100m/座標単位**。
- 上表は**制作上の採用基準**であり、世界全体の大きさや国家の位置を確定するものではない。
- 町・建物・湾が1枚で収まらない場合は、同じ縮尺で複数の隣接マップに分割可能。広さのために勝手に縮尺を変更しない。

## 3. 地図の親子階層と制作順

- 地図ツリーの基点：`異世界 (rasetsu_otherworld) > 旧世界 (rasetsu_old_world) > 大陸地図（仮） (rasetsu_old_world_continent_draft)`。
- **当面は大陸から制作する**。世界地図は大陸の数・位置・世界規模が未決定のため暫定表示とし、正式な世界の外形を先に描き込まない。
- 大陸図は1000×1000マス、1マス＝5km、地図範囲5000×5000km。`rebuild/scenes/rasetsu-old-world-continent-draft.scene.json` を編集する。
- 既存の世界図 `rebuild/scenes/rasetsu-old-world.scene.json` は参考・仮案。世界全体の実測図とみなさない。
- 国家→地方→都市→街区→内部の地図は必要になってから追加。親地図で小さすぎる施設・道・橋・建物を実寸描写しない。
- 親地図では重要地点を **アイコン／概略記号** で置き、詳細は下位シーンへ。地図の階層切替は明示的なリンク・選択で行う。ズームだけで勝手に階層移動しない。

## 4. 確定した地理条件・大陸表示での扱い

- **ジェンダードーン**：海上の孤島。**招かれた者のみ島を発見できる**。通常の航行者が発見できる位置・通常航路として扱わない。隠蔽の仕組み（霧、魔法、結界等）、島の座標と距離は未確定。
- **黒天守国**：海に面し、海から陸へ **U字型に入り込む湾** がある。国の陸域が湾を囲む。湾内の**中央付近で海寄り**の小島に **閻魔羅闍** がある。周辺には沿岸の約5区画と小島に向かう橋があるが、各区画の位置や橋の形状は未決定。
- **閻魔羅闍の小島**：面積は**東京ドーム程度**というユーザー指定。大陸図の5km/マスで輪郭を正確に描けないため、重要地点の記号にし、後で国家・地方・拠点級の詳細図で実寸に沿って設計する。
- その他、大陸下書きの地域は **ヴァルストーク／ディンディール／フェルガルド草原／竜人圏** を含めた6地域。固有の地形・性格はNotion個別地域ページを確認する。
- 既存の大陸輪郭・各国間の方位・距離・国境・海岸線は**仮配置**。地図上で隣接していることを既定設定と解釈しない。

## 5. 変更時の作業手順（毎回）

1. Notionの「鬼武神ラセツ > 制作・参照ルール」と、対象の「地域・国家」等の正本を確認する。
2. **このファイル**、[SCENE_FORMAT_v2.md](./SCENE_FORMAT_v2.md)、[RASETSU_MAP_CHANGELOG.md](./RASETSU_MAP_CHANGELOG.md) を読み、確定事項・未確認事項・既存修正を区別する。
3. `rebuild/map-tree.json` と編集対象の `rebuild/scenes/*.scene.json` を最新のGitHubから取得し、現行JSONを検証する。
4. 地形・国境などの案は `description/detail/metadata` で「仮」を明記する。ユーザーから明示された設定だけを確定扱いにする。地図オブジェクトが表現できないほど小さい場合は記号化する。
5. 親子関係と縮尺を維持し、**既存の地球・艦内マップ、他の地域、defaultMapIdを勝手に変更しない**。大規模編集前に複製や差分確認を行う。
6. `schemaVersion:2`、図形の型／点列／親ID／重複ID／マス数／距離換算の整合性を検証する。編集したファイルを読み戻す。GitHub Pages公開後の視覚確認は、未実施なら未実施と明記する。
7. **変更履歴ファイルへ日付・対象・変更理由・確定／暫定の区別・影響範囲・未解決事項・コミットを追記する。** 古い内容を上書きして消さない。
8. 作業結果には編集・閲覧リンクと、まだ調整が必要な点を示す。
