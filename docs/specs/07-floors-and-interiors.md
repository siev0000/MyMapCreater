# 07 建物内部・複数階フロアの設計仕様

状態: **設計確定候補／本格実装前**。フロア切替と仮設備の表示だけ試験済みであり、壁の開口、扉、階段接続、フロア編集UIは**未実装**。この文書は実装に必要な共通設計と受け入れ条件を規定する。既存シーンの世界設定・配置は変更しない。

## 目的と既存ルール

- 内部区画Aのような下位区画も、必要に応じて**独立した建物（階を持つ施設）**として使える。名称や特定のIDで特別扱いしない。
- **マップ階層**（船→中層シーンなど）、**表示Lv**（地区→施設→内部区画→室内設備）、**物理階**（B1F、1F、2Fなど）は独立。階を上げても `displayLevel` は変わらない。
- 周囲の地図は保持し、Lv3の選択でLv4、Lv4の選択でLv5を表示する。内部へ入る専用ボタンは不要。
- 閲覧のフッターは操作情報を**一行**に収める。選択中の名前を優先、親名は小さく省略。物理階は**ドロップダウン一個**、戻る操作は必要なら🔙だけ。残りの領域を説明文に使う。
- 編集機能はまず**2D平面図**で完成させる。建物内部で背景として周囲の区画を残し、現在階の内部だけを通常表示する。他階参照は薄い表示（ゴースト）を任意設定。
- 施設の間取り・階数・具体的な寸法は既存の仮データを正式設定として扱わず、個別に確定する。

## 共通グリッド・実寸基準（採用）

- **標準は1マス＝0.5m（50cm、2マス＝1m）**。建物・道路・外壁・入口・室内設備が同じ実寸基準で位置を共有する。
- **補助スナップは0.5マス＝0.25m（25cm）**。配置時の精度を上げるだけで、基本グリッドを建物ごとに作り直さない。
- グリッドの原点・軸方向・単位換算は**シーン全体で共通**。建物はそのグリッド上の外形と使用範囲を持つ。階ごとの床・壁・扉・階段は同じ建物基準で位置合わせする。
- 編集画面ではグリッドと補助スナップのON/OFFを選べるようにする。閲覧画面では通常グリッドを隠し、必要なときだけ表示できるようにする。
- 壁・家具はグリッドスナップを基本とし、扉・窓の開口は壁上で任意位置・任意幅も指定可能。スナップが必要な実寸配置を妨げない。
- **注意：既存シーンJSONの座標値にm単位が確定しているわけではない**。既存の`grid.spacing:100`などは現在の描画用座標間隔であり、0.5mを表すとは限らない。導入時にシーン座標↔メートルの変換係数を明示し、既存の位置や寸法を無断で変換しない。
- 建物のマス数は建物外形と座標換算から決まる。内部区画Aの幅51×奥行66も現時点では座標単位であり、実寸や確定したマス数を意味しない。
- **状態：仕様採用。エディターのスナップUI・実寸換算・建物共通グリッド描画は未実装。**

## 建物を構成するオブジェクト

| 種類 (`objectType`) | 用途 | 主な編集操作 |
|---|---|---|
| `facility` | 建物本体・内部区画の親。複数フロアを持てる | フロア作成・編集、外形指定、配置 |
| `floor`（概念上） | `facility.floors[]` の一要素。通常は独立描画オブジェクトにしない | 階の追加・削除・複製・並べ替え |
| `slab` | その階の床面、床の抜け、吹き抜け | 多角形作図・開口設定 |
| `room` | 室内の部屋、廊下、ホール | 図形作図・名称・用途 |
| `wall` | 外壁と内壁。折れ線/線分、厚み、高さ | 頂点操作・接合・分割 |
| `door` | 壁の開口と扉。壁IDを参照 | 壁上に配置・幅・開き方向・通行状態 |
| `window` | 壁に設けた窓。壁IDを参照 | 壁上に配置・幅・高さ |
| `stair` | 上下の階をつなぐ階段。両端を明示 | 始点階・終点階・踊り場・向き |
| `elevator` / `ramp` | 垂直/スロープ接続 | 接続階の明示 |
| `object` | 家具・設備・小物。既存オブジェクトと互換 | 配置・回転・寸法・選択 |

`objectType` は意味（施設/壁/扉等）を示し、`geometry.type` は描画形状（rect/polyline/polygon等）を示す。分類と描画を混同しない。

## データ構造（導入予定：Scene v2拡張）

既存の `objects[]` と `parentId` は維持。建物が `floors[]` を所有し、子オブジェクトが `floorId` を参照する。オブジェクトIDはシーン内で一意。以下は**概念例**で、現行コードが全フィールドを扱えることを意味しない。

```json
{
  "id": "sample-building",
  "name": "建物テスト",
  "objectType": "facility",
  "displayLevel": 4,
  "parentId": "sample-district-facility",
  "geometry": {"type":"rect","x":100,"y":100,"width":50,"height":65},
  "floors": [
    {"id":"1F","label":"1階","elevation":0,"height":3.2,"outline":{"type":"polygon","points":[[0,0],[50,0],[50,65],[0,65]]}},
    {"id":"2F","label":"2階","elevation":3.2,"height":3.2,"outline":{"type":"polygon","points":[[0,0],[50,0],[50,65],[0,65]]}}
  ]
}
```

所属するオブジェクトの例:

```json
[
  {
    "id":"sample-room-1",
    "name":"部屋A",
    "parentId":"sample-building",
    "objectType":"room",
    "displayLevel":5,
    "floorId":"1F",
    "coordinateSpace":"parentLocal",
    "geometry":{"type":"rect","x":2,"y":2,"width":25,"height":25}
  },
  {
    "id":"sample-wall-1",
    "name":"廊下との境壁",
    "parentId":"sample-building",
    "objectType":"wall",
    "displayLevel":5,
    "floorId":"1F",
    "coordinateSpace":"parentLocal",
    "geometry":{"type":"polyline","points":[[27,2],[27,30]]},
    "structure":{"thickness":0.25,"height":3.0}
  },
  {
    "id":"sample-door-1",
    "name":"部屋A入口",
    "parentId":"sample-building",
    "objectType":"door",
    "displayLevel":5,
    "floorId":"1F",
    "coordinateSpace":"parentLocal",
    "opening":{"wallId":"sample-wall-1","distance":8,"width":2.0},
    "door":{"hinge":"start","swing":"inward","state":"closed"}
  },
  {
    "id":"sample-stair-1",
    "name":"階段",
    "parentId":"sample-building",
    "objectType":"stair",
    "displayLevel":5,
    "floorId":"1F",
    "coordinateSpace":"parentLocal",
    "geometry":{"type":"rect","x":31,"y":35,"width":8,"height":16},
    "connection":{"fromFloorId":"1F","toFloorId":"2F","fromAnchor":[35,43],"toAnchor":[35,43],"direction":"up"}
  }
]
```

注: `opening` の `distance` は壁のポリライン始点からの累積距離（壁長と同じ座標単位）。扉が固定座標で壁とずれる問題を防ぐため**壁への参照を正本**とする。扉の開口幅が壁の長さを超える配置は不可。階段の `toAnchor` は到着階のローカル座標であり、図形が同じ位置に重なるだけでは接続したと判定しない。

## 床・壁・扉の描画規則

1. 各階の床 `outline` を表示し、必要なら `holes[]` で吹き抜け・床欠損を抜く。床と部屋の塗りは透明度を制御し、上位区画のベタ塗りが設備を隠さないようにする。
2. 壁は`polyline`の線分列と `structure.thickness` から描画。見た目の太さとクリック判定は連動。ただし見た目の最低1px程度は画面上で確保。
3. 扉・窓は`opening.wallId`が示す壁上の**開口区間**を計算する。壁はその区間を描かず、開口と扉記号（扉葉・開く方向の弧）を別途描く。壁の上に扉アイコンを載せただけにはしない。
4. 壁の移動・回転・長さ変更時は、開口距離を検証して扉・窓を追従させる。開口区間が壁端や他の開口と競合した場合は警告して保存を止める（勝手な削除や強制移動をしない）。
5. 部屋・扉・階段・家具は別々の選択対象。最上面の表示Lvとフロアが一致するものだけ選択できる。非アクティブ階は誤編集を防ぐ。
6. 2階を選ぶと**1階の壁・家具は通常表示しない**。同位置を比較したいときだけ1階を淡色の参照表示にする。

## 階段・フロア間接続

- `stair` / `elevator` / `ramp` は `fromFloorId` と `toFloorId` を必須とする。双方が同じ建物の有効な階IDであること。
- 上り・下りは矢印と階段段差の線で区別する。表示階が接続元であるとき、**「移動先の階を表示」**操作で相手の階へ切り替える。
- 接続先フロア側にも着地点を表示する。二つの別IDの階段を作らなくても、**同じ接続ID**で往復できる。
- 扉は同一階の部屋↔廊下や室内↔外部の通行口を示す。開閉・施錠・通行可否は表示属性とし、将来の経路探索では別途通行グラフで判定。
- 接続先が階の外形外、吹き抜けに落ちる、床がない等の幾何チェックを行う。階段は建物の物理階を切り替えるが、表示Lvを勝手に変更しない。

## 座標・編集の所有関係

- 建物外形は従来どおり**シーン座標**で保持。建物内の部屋・壁・扉・階段・設備は `coordinateSpace:"parentLocal"` で建物左上（矩形でない場合は定義済み原点）を `(0,0)` とするローカル座標を持つ。
- 建物を動かしても子のローカル座標を再計算しない。描画/クリックの直前に親の変換を適用する。現行の世界座標の子オブジェクトは移行まで `coordinateSpace` 省略で維持。
- フロア外形・床・壁と階段の位置合わせは同一ローカル座標系で管理。建物の回転・拡縮を追加する場合は親変換に統一し、複数箇所で二重変換しない。
- フロア複製時は対象階に所属する全子IDを生成し直し、扉の `opening.wallId` など内部参照と接続先IDを再配線する。複製後の階段は接続先をユーザーが指定するまで「未接続」として保存不可。

## エディターに必要な操作

1. 建物選択時に**「フロア」パネル**を表示。階の追加、名称・高さ変更、削除、複製、並べ替え。階選択は単一リストで、編集対象階を常に明示。
2. 建物内編集モードで「床」「部屋」「壁」「扉」「窓」「階段」「家具」「設備」の作図ツールを追加。追加した物体は現在階と建物を自動設定。
3. 壁ツールはクリックで頂点追加、終点ダブルクリックで確定。頂点移動・壁分割・端点スナップ・直角補助。扉ツールは**既存の壁をクリック**して開口位置を指定し、幅/開き方向を設定。
4. 階段ツールは元階に図形を描き、到着階と着地点を選択する。接続結果は閲覧画面で往復確認できる。
5. 選択階以外の図形はロック。ゴースト参照をONにしても編集対象にしない。
6. 保存時にスキーマ検証を実施。エラーは該当物体のIDと問題の箇所を明記。JSON保存・再読み込み後も編集対象階と図形の対応が維持される。

## 保存検証で必ず守る不変条件

- シーン内のID重複と親子循環禁止。
- `floorId` があるオブジェクトは、最も近いフロア所有者（建物）の `floors[]` に存在するIDを参照。
- `door/window.opening.wallId` は同じ建物・同じ階の `wall` にだけ参照可能。開口は壁の線上かつ壁の端からはみ出さず、開口同士が重複しない。
- `stair/elevator/ramp.connection` の始点・終点階は有効で異なる階。着地点は対応する床の有効領域内。
- フロア削除時に所属設備や接続が残るなら削除を拒否し、移動先の指定か対象設備の明示削除を求める。
- 旧シーン・建物外部の一般オブジェクトは引き続き読み込める（段階的移行）。

## 実装順序と受け入れ試験

| 段階 | 実装内容 | 合格条件 |
|---|---|---|
| 1 基礎 | スキーマ検証・ローカル座標・フロア外形・編集時の階選択 | 既存シーン無破損、2階の切替/保存/再読み込み |
| 2 間取り | 床・部屋・壁・扉・開口描画・壁の編集 | 壁に扉を置くと本当に開口し、移動時も連動 |
| 3 階間接続 | 階段・エレベーター・スロープ・着地点 | 1F→2F→1Fの往復切替が可能、接続先不正を拒否 |
| 4 編集効率 | 複製、削除保護、スナップ、ゴースト、誤選択防止 | 複製後ID/壁参照/階段参照が壊れない |
| 5 テスト建物 | 内部区画Aに**正式ではない**床/廊下/室内/壁/扉/階段/設備を配置 | 2階建ての階を切替え、各階の扉と階段を操作できる |
