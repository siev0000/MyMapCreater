# 09 室内物資用 文字アイコン対応表

状態: **アイコンと分類の基本対応を承認済み**（2026-11-08）。現行Scene v2のアイコン描画機能は未実装。

## 適用範囲

- 対象は**家・施設の部屋に置く物資や収納物**の簡易識別。図形（収納棚、箱、床上の置き場所など）に文字アイコンを重ねて表示できる。
- 家具・大型設備・部屋・建物は原則として図形で表現し、ここにあるアイコンを強制しない。
- **1アイコン＝1つの基本物資分類**とする。同じ分類の個別物資は別のID・名称・説明で区別できる。アイコン文字だけで数量や詳細を決定しない。
- 下表の30種を基本対応表として登録する。実際に置く物資は編集者が指定し、マップへ自動生成しない。

## 図形との併用

- **図形**：物資が置かれた範囲・サイズ・向き・選択位置を表す。
- **文字アイコン**：中身の種類を示す。中央配置を基本とし、色・表示サイズ・オフセットを独立に設定する。
- **名前ラベル**：必要な場合だけ追加。アイコンとラベルは別々に表示/非表示を切り替えられる。
- 複数種類を収納する場合、箱そのものに単一アイコンを強制しない。複数アイコン、文字ラベル、または中身の一覧という選択肢を今後検討する。

## 初期図形の設定案（30分類）

対応表にある30種類について、**図形＋文字アイコンをセットにした初期値**をJSONへ登録した。

[初期図形プリセット案（JSON）](09-indoor-supply-shapes.example.json)

| 基本図形 | 主な対象 | 意図 |
|---|---|---|
| 矩形 | 梱包物資、工具箱、建材、木材、衣服、寝具、書籍など | 収納箱・束・積載範囲を簡略化 |
| 円形 | 機械部品、鉱石、糸、繊維束、飲料、水、試薬、試料など | 小さな物資の占有範囲を簡略化 |

- 図形の幅・高さは**仮のマップ座標値**であり、現実の寸法や決定済みゲーム数値ではない。
- 図形は対象物の正確な外観を描くものではなく、配置範囲を示す簡易形状。
- アイコンは図形中央に重ねる設定案。後から形・寸法・角度・表示方法を編集できる前提。
- **このJSONはアプリ未接続の設計データ**。現行Scene v2に投入する形式ではなく、配置エンジンへの組み込みは別途実装が必要。

## プリセット案

物資プリセットを変数・JSONとして定義し、同じ設定を再利用する。以下は**次期スキーマ案**で、現行Scene v2には直接投入しない。

```json
{
  "presetId": "supply_box",
  "name": "箱入り物資",
  "geometry": {"type": "rect", "width": 40, "height": 30},
  "icon": {"text": "📦", "visible": true, "position": "center", "fontSize": 18}
}
```

位置・親部屋・フロア・個数などの配置固有値は各設置物に保持する。

## 使用上の注意

1. 絵文字の形・色・大きさはOS・ブラウザー・フォントで変わる。**プレビュー確認**を必須にする。
2. アイコンが使えない環境では名前または単色の代替記号で表示する。未対応文字で描画を止めない。
3. 通行障害・重量・所有者・数量などの物資属性を文字アイコンの種類から推定しない。
4. 著作権付きの独自アイコン画像は使わず、Unicodeの文字・記号とJSONで管理する。
5. 対応表を変更する場合は本仕様書を更新する。既存の物資分類・プリセットを黙って再割当てしない。完成目標は**室内の物資を識別できること**であり、全分類の自動配置ではない。
