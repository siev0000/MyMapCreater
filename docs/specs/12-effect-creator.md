# Game Creator Tools / エフェクト作成 v1

- 入口: ルート index.html をツール選択画面にする。既存のマップ・名前生成・図形カタログの機能は維持する。全ツールのヘッダーに共通ホームアイコン（shared/tool-home.js / .css）を配置し、確認OK時のみ選択画面に遷移する。キャンセルは現在画面を維持する。自動保存やブラウザーの戻る操作への警告は追加しない。
- effect-creator は独立した静的HTML/CSS/JS。ゲーム本体のデータ、マップデータは編集しない。
- Canvas描画の基本18種類、最大32レイヤー、色/発光/粒子数/乱数シード/位置/角度/サイズ/不透明度/開始終了時点を編集する。各レイヤーは開始終了値の線形補間。すべての描画は固定時間・シードに基づく。
- プレビューと出力は同じ draw 関数。FPS、時間からフレーム数 round(FPS × 秒数) を算出（最低1枚）。フレームiは i/FPS 秒、末尾時点は重複させない。列数0は横一列。
- 背景はプレビューだけ。PNG、WebP、連番PNG ZIP、JSONをダウンロード。WebP未対応時はエラー。シートは最大辺16384px/3200万画素、ZIPは総計1億画素を上限とする。
- コードモードは HTML/CSS/JS の sandbox iframe プレビュー、HTML保存。インラインSVGの対応CSSスタイルを各フレーム時点で固定して画像化する方式と、ユーザー定義の window.renderFrame({canvas,ctx,time,duration,frame,fps}) を各時点で呼ぶCanvas方式を用意。出力形式は共通。SVGの外部画像、foreignObject、SMIL、疑似要素、HTML要素全般、CSSの全プロパティを対象にした忠実なラスタライズは非対応。GIF、WebGL、任意中間キーフレーム、画像レイヤー、既存画像編集/動画/戦闘計算統合は未実装。コードモードの画像出力は実ブラウザー未検証。コードモードのHTMLは信頼できる入力を使用。外部アクセスをCSPで制限し、親オリジンにはアクセス不可。無限ループ等の負荷制限はない。
- 静的サイトのため書き出しとGitHub反映は別工程。
- テスト: node tools/effect-creator/test.cjs。実ブラウザーでの出力・見た目の検証は別途。

## モバイル画面

- ヘッダーを約34〜36px（端末の安全領域を除く）とし、共通ホームボタンを維持する。
- 760px以下では、残りの表示可能高さを上部プレビュー43%・下部設定57%の目安で分割。設定領域だけスクロールし、プレビューは常時表示する。PCでは左右2ペイン。短い横画面は比率を調整する。
- 設定はレイヤー・出力・保存・コードの4タブ。コードタブでは同じ上部プレビュー領域に隔離iframeと専用再生操作を表示する。タブ切替でエフェクトデータ・コード内容を消さない。
- プレビュー倍率の初期値は全体表示。手動100〜400%も維持し、はみ出す場合はプレビュー内スクロール。出力解像度には影響しない。
- 画面レイアウト検証: `node tools/effect-creator/layout.test.cjs`。実機の表示・操作は別途確認する。

## 外部描画エンジン試作（画像不要）

- 外部タブは既存Canvas・CSプリセットとは独立した設定・プレビューを持つ。外部ライブラリは起動ボタンでCDNから遅延読込。失敗時は明示し、既存Canvasは維持する。
- PixiJS 8.10.0 + pixi-filters 6.1.4、Three.js 0.169.0、three.quarks 0.15.7、Three.js GLSL ShaderMaterial、tsParticles 4.4.0 basic bundle。すべて図形・粒子・数式を生成する試作で、外部画像は不要。Quarksの粒子テクスチャはCanvasで生成する。
- Pixi/Three/GLSLは固定時刻、Quarksは固定ステップとシードを使う試作。共通PNG/PNGシート/WebPシート/連番PNG ZIP出力を接続。tsParticlesはリアルタイム試験なので静止PNGのみ、コマ送り・シート出力は無効化。各エンジンが使う設定の違いは画面に表示。
- 独立した試作JSON保存・読込、備考、既存の出力設定コピーを用意。ゲームデータ・既存雷魔法は変更しない。
- EffekseerForWebは既存素材の再生ランタイムのため、画像・素材なしの自作優先の今回対象外。外部ライブラリの実ロード・WebGL/スマホ・出力確認は未実施。CDN依存の試験機能であり、正式採用は動作確認後。
- モデルテスト: `node tools/effect-creator/external-model.test.cjs`。

## 描画エンジン比較画面

- ヘッダーの描画方式選択で Canvas 2D / PixiJS / Three.js / three.quarks / GLSL / tsParticles / SVG・CSS・JS を切り替える。外部方式は選択時に自動起動し、エンジンごとの入力設定はページ内で保持する。Canvasの魔法・レイヤー・出力・保存タブ、コード入力も維持する。
- 雷・電撃、爆発・火花、炎・上昇、旋風・渦、円環・魔法の比較サンプルを生成する。外部エンジンの初期サンプルは各方式に合わせて設定。直前の外部エンジンの設定コピーで同条件比較が可能。Quarks/tsParticlesは対応する粒子発生源の近似であり、全形状が同等に描けるわけではない。コードモードの比較サンプルは固定時刻Canvasコードを生成する。既存のSVG/CSS編集も利用可能。
- 画像出力中・外部起動中はエンジン切替を抑止。設定はブラウザを閉じるまで保持（既存JSON保存で永続化可能）。外部エンジンの実起動・画像出力は要ブラウザ検証。
