# Game Creator Tools / エフェクト作成 v1

- 入口: ルート index.html をツール選択画面にする。既存の rebuild/ のマップ・名前生成・図形カタログは変更しない。
- effect-creator は独立した静的HTML/CSS/JS。ゲーム本体のデータ、マップデータは編集しない。
- Canvas描画の基本18種類、最大32レイヤー、色/発光/粒子数/乱数シード/位置/角度/サイズ/不透明度/開始終了時点を編集する。各レイヤーは開始終了値の線形補間。すべての描画は固定時間・シードに基づく。
- プレビューと出力は同じ draw 関数。FPS、時間からフレーム数 round(FPS × 秒数) を算出（最低1枚）。フレームiは i/FPS 秒、末尾時点は重複させない。列数0は横一列。
- 背景はプレビューだけ。PNG、WebP、連番PNG ZIP、JSONをダウンロード。WebP未対応時はエラー。シートは最大辺16384px/3200万画素、ZIPは総計1億画素を上限とする。
- コードモードは HTML/CSS/JS の sandbox iframe プレビュー、HTML保存。任意DOM/CSSのラスタライズ、コードモードからの連番出力、GIF、WebGL、任意中間キーフレーム、画像レイヤー、既存画像編集/動画/戦闘計算統合は未実装。コードモードのHTMLは信頼できる入力を使用。外部アクセスをCSPで制限し、親オリジンにはアクセス不可。無限ループ等の負荷制限はない。
- 静的サイトのため書き出しとGitHub反映は別工程。
- テスト: node tools/effect-creator/test.cjs。実ブラウザーでの出力・見た目の検証は別途。
