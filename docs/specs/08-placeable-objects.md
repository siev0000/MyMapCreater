# 08 設置物・家具・大型設備の配置仕様

状態: **次期実装の仕様（未実装）**。ユーザー確定の完成範囲: **基本的な施設内部 + 大型設備・家具などを配置できるまで**。

## 初期完成範囲

- 部屋/フロアの上に、大型機械、タンク、制御盤、作業台、机、椅子、棚、ベッド、カウンター、コンテナ等を配置する。
- 物の種類ごとに固有の描画コードを作らず、**共通オブジェクト配置エンジン**で扱う。
- 細かな装飾品、1個単位の小物、キャラクター・NPCの管理/移動、3D家具モデルは**初期完成範囲外**。後から増やせるデータ構造にする。

## 各設置物に必要な情報

| 属性 | 説明 |
|---|---|
| `id`, `name` | 固有ID、名称 |
| `objectType` / subtype | 設置物の種類。固定家具、設備、移動可能な物などをデータで分類 |
| `parentId` | 部屋・施設などの親 |
| `floorId` | 所属する物理フロア |
| `displayLevel` | 詳細表示Lv。階数と混同しない |
| `geometry` | 矩形・多角形・円等の占有外形 |
| 位置、幅、高さ、角度 | 位置・大きさ・向き。親基準の座標を将来サポート |
| `style` / assetRef | 色/輪郭、またはアイコン・画像素材の参照 |
| `visible` / locked | 表示・非表示、編集ロック |
| `blocking` | 通行障害として扱うか。見た目で自動判断しない |
| `metadata` | 説明、材質、用途などの拡張属性 |

具体的な追加キーの正式名はスキーマ設計時に確定する。

## 必須編集操作

1. 矩形、円、ポリゴン等の簡易図形をそのまま設置物として利用できる。
2. 設置物を選択し、移動・拡縮・回転・複製・削除できる。
3. 設置先のフロア・部屋を指定する。親施設の移動に内部設置物が追従する。
4. 配置の精度を上げるスナップ（グリッド/壁/頂点）をON/OFFできる。
5. 同種設置物をまとめて複製、複数選択、整列できる。
6. 種別ごとに表示/非表示を切替え、必要ならロックできる。
7. 追加素材は外部アセット/URL/データ参照で管理し、特定世界設定の素材をエンジンに埋め込まない。
8. JSONの保存→再読み込みで位置・角度・外形・画像参照・所属階が一致する。

## 初期範囲と次期以降

**初期必須**: シンプルな2D設置物、共通配置、フロア関連付け、移動/回転/複製、サイズ変更、グループ/整列、任意の通行障害フラグ、JSON保存。

**後回し**: 家具ごとの専用UIや動作シミュレーション、細かな小物・装飾、人物/ロボットの配置・アニメーション、照明シミュレーション、3D表示。

設置物は床・壁・扉の代用にはならず、区画境界から自動生成しない。異なる役割はオブジェクトとして分離する。

## 室内の物資表示と図形プリセット（次期仕様）

文字アイコンの**主な用途は、家・部屋の中に置く物資や収納物の簡易表示**とする。建物全体・施設・大型設備を一律に絵文字で描く方針ではない。

- 施設・部屋・壁・扉・大型設備・家具：**図形を基本**とし、形状・寸法・向き・位置が伝わる描画を優先。
- 室内の物資・収納物：必要に応じて図形の上に**文字アイコンを重ねて**識別する。文字だけ、図形だけの表示も可能。
- アイコンは装飾/識別であり、占有面積・衝突・通行判定は独立して設定する。
- アイコンの位置、文字、色、サイズ、表示/非表示は図形の設定と独立。
- 文字アイコンの見た目は端末やフォントで異なる場合がある。正確な向き・間取り表現には図形を使う。

### プリセット（設定値を再利用）

一度登録した**図形・寸法・色・必要に応じた文字アイコン**の組み合わせをプリセットIDから呼び出して、部屋/フロアへ配置できるようにする。

- プリセットID・名称・図形・基準寸法・色・任意の文字アイコンを定義する。
- 設置物ごとに位置・親部屋・所属フロア・回転等を保存し、必要に応じて設定値を上書きする。
- 同じプリセットを複数配置・複製できる。
- 既存プリセットの変更を配置済みオブジェクトへ自動反映するか、配置時の設定を固定するかを明示的に選べるようにする。
- 建物、設備、家具、物資を特定のアイコンへ強制的に対応づけない。

### 受け入れ条件

1. 家の部屋へ「図形＋📦」の物資を配置できる。
2. 家具や大型設備を文字アイコンなしの図形だけで配置できる。
3. プリセットの選択・複数配置・回転・サイズ調整ができる。
4. アイコンの表示切替で図形の形状や占有範囲が変わらない。
5. 保存・再読み込み後も同じ設定が再現される。
