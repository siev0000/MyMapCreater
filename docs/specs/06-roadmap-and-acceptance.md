# 06 施設内部まで作るための開発タスク

## 到達目標

一般的な世界・町・施設・船・建物を対象に、**施設の内部（複数フロア・部屋・廊下・壁・扉・階段・大型設備・家具）まで一つの汎用アプリで作図**できる。階層は数値管理で、5段階に固定しない。既存マップの位置と色は勝手に変更しない。

## 推奨する実装順

1. **階層を正規化**: 表示LvとparentIdを独立に持ち、旧Scene v2の互換と移行レポートを用意。
2. **重なり解消**: 親の色が子と二重描画されないよう汎用の表示条件を整備。
3. **図形編集を強化**: 施設内部の壁/床/部屋/ポリゴンを直接作成。
4. **扉/開口/接続**: 壁線と扉を紐づけ、通行判定に必要な情報を保存。
5. **フロアと設置物**: 物理階層の切替・階段接続・大型設備/家具配置。
6. **親子移動・編集安全性**: ロック・Undo/Redo・コピー・回転。
7. **検証と公開**: 町サンプル + 既存中層シーンを併用して回帰確認。

## 完成範囲外（将来拡張）

小物の個別管理、装飾、キャラクター配置・行動、**3D表示そのものの実装**や断面立体図は現時点で必須としない。ただし、**将来の3D化に必要な情報を2D制作段階から失わずに保存することは必須の設計要件**とする。詳細は [07](07-floors-and-interiors.md)・[08](08-placeable-objects.md)・[2D→3D移行メモ](../2d-to-3d-transition-memo.md)。

## 2D優先・将来3D化に向けた制作タスク（2026-11-09 確定方針）

**確定した方針**：MyMapCreaterの主機能は2Dマップ制作・編集。3D地形や3Dエディターを今すぐ実装する必要はない。将来は**同じマップデータから2D表示と3Dプレビューを生成**することを目標とし、現在のScene v2と既存マップ・建物テンプレートの互換性を壊さない。

| 優先 | タスク | 状態 | 受入条件 |
|---|---|---|---|
| P0 | 既存Scene v2にある地形標高・建物高さ・道路幅の保存状態を監査 | 未着手 | 値が実測・推定・手動編集・未設定のどれか区別できる |
| P0 | 高さ情報の未設定を0mとみなさない | 設計決定／実装・回帰未検証 | 欠測と基準高0mを識別し、勝手に高さを補完しない |
| P0 | X/Y座標・座標単位・地理座標原点・標高基準を明示する | 一部対応（咲花駅は1m=4世界座標） | 任意地域と架空マップの尺度を変えずに高さを扱える |
| P1 | 地形の標高データを見た目の矩形セルとは分離して保持 | 未実装／現状は400矩形セル | 元DEMの由来・解像度・欠測・高さを保持し、2Dセル表示を再生成できる |
| P1 | 道路の頂点ごとの高さ・橋・トンネル・地形追従方式を定義 | 未実装 | 坂と平面交差・立体交差を区別でき、誤って道路接続しない |
| P1 | 建物の地盤高・建物高さ・階高・屋根の未設定値を整理 | 部分実装（高さmフィールド） | 未知の高さを仮の0mや勝手な階数にせず保存・編集できる |
| P1 | 河川・設備の水面高・設置高・参照する地形や階を整理 | 未実装 | 地形と独立した高さ／階の関係を保存可能 |
| P2 | 2D地形編集・道路接続・建物配置の制作機能を完成させる | 一部実装、実ブラウザー未確認 | Undo/Redo・保存・再読込・既存マップ互換を確認 |
| 将来 | 2Dデータを読む**別描画器**として3Dプレビューを試作 | 未着手・現時点の必須範囲外 | 元の2D制作画面・データを変更せず、地形の立体表示を切り替え可能 |
| 将来 | 3D上の道路・建物・橋・トンネル・内部構造へ拡張 | 検討中 | 不足した構造を追加設定でき、2D元データを破損しない |

**変更してはいけない設定**：既存マップの座標・縮尺・図形・色・レイヤー・親子関係、保存済み咲花駅の地理データ、現代住宅46テンプレート。3D化の都合で現在の2D表現を強制変更しない。

**未確認・検討中**：具体的な高さデータのスキーマ名、標高グリッドの保持方式、3D描画ライブラリー、地形補間と衝突判定、建物の屋根・内部立体化。データ項目を変更する前に既存Scene v2と衝突しない移行設計・回帰テストを行う。

## 住宅テンプレートの縮尺・設計根拠監査（2026-11-10）

**確認できた実装**：
