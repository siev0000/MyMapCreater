# 03 図形・座標・編集操作

## 現行の描画形状

- `rect`: x, y, width, height
- `polygon`: points
- `polyline`: points
- `circle`: center, radius
- `ring`: center, innerRadius, outerRadius
- `none`: ラベル/情報のみ

すべてマス目ごとではなく**自由な世界座標**。グリッドは `grid.spacing` 等で独立設定。投影方向は `coordinateSystem.horizontal/vertical` に従う。

## 目標操作（施設内部まで作成するため必須）

| 操作 | 期待動作 | 状態 |
|---|---|---|
| 図形追加・複製・削除 | 任意の種類・親・座標で編集 | 基本実装済み |
| 図形ドラッグ移動 | 編集モード時のみ移動 | 実装済み |
| 四角形のハンドル | 四隅/各辺からサイズ調整 | 矩形8ハンドル実装済み（回転時除く） |
| 多角形/線の頂点編集 | 頂点ドラッグ、途中挿入、削除 | 実装済み（辺ダブルクリック・操作パネル対応） |
| マウス/タッチで直接作図 | 線/多角形のクリック追加、確定/取消 | 未実装 |
| 回転 | 角度を数値/ハンドルで設定 | 矩形の数値回転のみ実装済み |
| スナップ | グリッド・頂点・辺・中心の独立ON/OFF | グリッドのみ実装済み、その他未実装 |
| 複数選択 | 複数図形の一括移動・整列・ロック | 未実装 |
| 親子移動 | 親移動時に内部子も追従・明示的に切替 | 未実装 |
| Undo/Redo | 作図・頂点・親子変更等を一操作単位で戻す | 基本実装済み・拡張要 |
| スマホタッチ | ピンチは地図、作図は操作モードを明示 | 実ブラウザー検証要 |

**数値入力は直接編集と併用**し、ピクセルの見た目と実寸座標を混同しない。描画の `strokeWidth` は画面px、実際の壁・道路の幅は別のデータフィールド。

## 編集状態

閲覧モードではパン・ズーム・選択。編集モードでは作図・頂点編集・サイズ変更。選択の切替だけではデータを変更しない。未保存状態を明示し、取り消しと保存前差分を持つ。

## 施設内部の作図フロー（目標）

親施設を選択 → 内部編集へ → 床/部屋/間仕切りを追加 → 壁・扉を配置 → 部屋・設備を命名 → JSONを検証・書き出し。

既存の外周図形を壁とみなして自動生成しない。図形の形状・位置・種類はユーザー指定優先。

## 親子連動移動（2026-11-09 初期実装）

- エディターのドラッグ移動・図形のX/Y（または円の中心X/Y）の数値変更時に、**選択オブジェクトと全子孫**を同じ座標差分で平行移動する。
- 追従対象は矩形、円、環状図形、多角形・折れ線、ラベル位置、階段の`connection.fromAnchor`/`toAnchor`。所属フロアや親子IDは変更しない。
- 未読み込みの`interiorSource`を持つ建物は、内部読み込みが完了するまで移動を拒否する。建物本体だけ動かして内部JSONの絶対座標を置き去りにしないため。
- 子孫ごとのスナップは行わず、**親の移動差分を一度だけ適用**して相対配置を保持する。操作単位のUndo/Redoは既存履歴を使用する。
- 未対応: 道路・隣接する別建物など**親子外の接続先**の自動移動、直接頂点編集や幅高さ変更による内部伸縮、別シーンをまたぐ連動、複数選択・回転。
- 実装の構文・Scene v2整合性と、内部区画Aの親＋32件を平行移動して他の104件に影響がないことは検証済み。実ブラウザーでの視覚・タッチテストは別途必要。

## マップ上の直接拡縮・頂点移動（2026-11-09 初期実装）

- エディターの「移動モード」をONにして図形を選択すると、**矩形は四隅と各辺の中央の計8か所**、多角形・折れ線は各頂点に編集用の黄色いハンドルを表示する。
- ハンドルをドラッグすると、矩形は端点位置と幅・高さを変更し、多角形・折れ線は指定した頂点だけ移動する。グリッドスナップ設定を尊重し、矩形の幅・高さが0未満にならないよう制限する。
- 図形内側のドラッグは従来の**親子連動の平行移動**。編集ハンドル操作は移動より優先する。タッチで2点操作した場合はピンチを優先する。
- 選択オブジェクトの形だけを拡縮し、内部の壁・家具・休眠ポッドなどの**子オブジェクトの寸法や位置は自動変更しない**。建物内部の意図しない変形を防ぐため、親子の拡縮連動は別設計とする。
- 直接編集も既存のドラッグ操作と同じ履歴単位でUndo/Redoに対応。建物内部が遅延ロード未完了の場合、建物本体のハンドル変更は拒否する。
- 未対応: 頂点追加・削除、回転、複数選択、辺への吸着、拡縮に追従する壁・扉・階段の自動再配置。PC／スマホ実画面での操作検証は未実施。

## 頂点操作・回転・閲覧グリッド（2026-11-09 追加）

- **頂点追加・削除**: エディターで多角形／折れ線を選ぶと「編集する頂点」「追加位置」「頂点を追加」「頂点を削除」を表示する。選んだ辺の中点に頂点を挿入する。多角形は3点、折れ線は2点未満には削除できない。
- **マップ上の直接操作**: 編集モードで選択中の多角形／折れ線の辺をダブルクリックすると、その位置に新しい頂点を追加する。頂点ハンドルはAlt＋クリックで削除できる。タッチ端末では右パネルの操作ボタンを使える。操作は既存Undo/Redoに登録する。
- **図形の回転**: 矩形図形は座標設定の「回転角度（度）」から中心を基準に回転する。描画と当たり判定を回転角に対応させる。回転後の四角形は手動のX/Y/幅/高さ入力で変更する（回転済み矩形の画面上のサイズ変更ハンドルは今回未対応）。多角形・折れ線・円の回転は別タスク。
- **閲覧側グリッド切替**: 閲覧ページの拡縮ボタン横に▦ボタンを置き、マス目のON/OFFを切替可能。設定はブラウザーのlocalStorageへ保存。元シーンの`grid.visible`を変更せず、地図そのものの保存内容に影響させない。高密度時には視認性のため自動で格子線描画を省略する。
- 図形ハンドルのドラッグ・頂点追加削除・回転をまとめて直接編集機能とし、既存の親子平行移動は維持する。
