# 11｜建物内部・入口・間取りの生成ルール（制作・検証基準 v1）

更新日：2026-11-10

## 状態・適用範囲

- **確定（ユーザー指示）**：既存マップの建物の中に内部を作る。駅を別マップへ増やさない。既存外形と向きを保持する。入口がない状態を完成としない。
- **既存実装仕様**：Scene JSON v2、親子関係 `parentId`、物理階 `floors[] / floorId`、壁 `objectType:wall`、扉 `objectType:door` と `opening.wallId` は既存仕様を尊重。
- **新規制作ルール（本書）**：幾何・入口・接続・検証の必須条件。制作に使うが、未実装の自動検証を「対応済み」と呼ばない。
- **未確認**：現実世界の建物用途、正確な入口位置、室内寸法・階数、咲花駅の駅舎輪郭。OSM建物外形だけで決めつけない。

参照：`04-walls-doors-and-connections.md`、`07-floors-and-interiors.md`、`05-data-and-validation.md`、`../../rebuild/SCENE_FORMAT_v2.md`。

## 作成手順（必須）

1. **既存の対象を特定**：親建物ID、外形の頂点、地図の縮尺、表示Lv、既存の出入口・道路・階を取得。親が不明なら生成しない。位置マーカーは建物外形ではない。
2. **外形の保護**：元の `geometry`（座標・回転・頂点）、OSM ID、道路・線路・地形を変更しない。追加は子オブジェクトのみ。世界やマップを新設しない。
3. **ローカル座標系**：建物の長辺などから局所軸を決定。内部の室・壁・家具は同じ局所軸から世界座標へ変換。外接矩形にそのまま水平長方形を描かない。凹・斜め建物は外形内にクリップして検証。
4. **床・外壁の扱い**：境界ポリゴンが即「壁」を意味するわけではない。壁を設ける際は独立した `wall` を明示。既存外形を改変せず、必要な壁線は子オブジェクトとして参照/作成。
5. **入口を先に決める**：最低1か所の**明示的な屋外出入口**が確保できてから間取りを確定する。既存情報があれば優先、なければ「仮入口」として候補辺上へ置く。道路・通路側は**距離だけで確定しない**。歩行動線不明なら仮候補と記録。
6. **入口の構造**：`door` には独立ID、設置壁ID（実装スキーマ `opening.wallId`）、壁上開口幅 `opening.width`、対応する位置を持たせる。壁を開口で切り欠いて表示し、入口に壁線が重ならないこと。開口のない「入口付近の設備」を入口として数えない。
7. **移動経路から間取り**：屋外→入口→玄関/共用部/廊下→室内扉→部屋、を成立させる。全室が完全な密室、室の重なり、廊下の断絶、壁を通過するだけのアクセスは不可。各室に実際のドアまたは明示した開口が必要。部屋を先に四角で並べて入口を後付けしない。
8. **階別の成立性**：複数階を仮設定する場合、階ごとの床・階段・接続先 `floorId` を整合。未確認階数を実在情報として表示しない。階段は単なる家具図形で代用しない。
9. **家具・設備**：部屋の用途が確定した後に配置。外形・壁・扉・廊下と重複しない。名称と占有寸法を持つ。必要に応じ移動可能な余白を確保。
10. **表示Lvと保存**：親建物のLvを `N` とする場合、直接の部屋・入口は表示条件が `N+1` で成立するように検証。物理階と表示Lvを混同しない。保存→再読込で同じ構成を維持する。

## 幾何検査（完成判定に必須）

- 内部ポリゴンの全頂点と**各辺の途中**が、元建物外形内（境界上を許容）にある。頂点だけの検査は不十分。凹型では交差・外への飛び出しも確認。
- 建物の回転角が異なるケース（0°・斜め・90°）と、矩形・L字・複雑多角形のケースで内部が回転追従する。
- 各部屋・壁・家具・扉は建物の親ID、階ID、固有IDを持つ。参照切れがない。
- **屋外出入口数は1以上**、実壁上に配置、入口の開口幅・方向に矛盾がない。入口が作れない形状は「未完成／要手動修正」と記録し、完成数に含めない。
- 屋外から共用部へ、共用部から各部屋へ移動可能な**接続グラフの根拠**がある。通行判定エンジンが未実装なら静的な接続検査や個別目視が必要。
- 駅については**駅座標マーカーを駅舎形状として扱わない**。駅舎の実体に対応する既存ポリゴンが確認できない場合、駅舎内部の配置は保留。ホームや線路の場所も模式図と実地図を混同しない。
- 既存の建物69件のうち「処理対象」「入口確認済み」「接続確認済み」「未完成」を**別々に数える**。生成件数＝完成件数としない。

## 実装上の禁止事項

- 建物外接矩形の中へ回転無しの部屋を自動配置して完成扱いする。
- 外形内部に設備を置いただけで屋外扉を設置したことにする。
- 既存駅と別に駅マップや建物を重複生成する。
- 実際の駅・住宅・旅館の内部を確認なしで「実物どおり」と表示する。
- 検証できない凹多角形や狭小建物を無理に埋める。
- 元シーンの保存済み外形・座標・標高を上書きする。
