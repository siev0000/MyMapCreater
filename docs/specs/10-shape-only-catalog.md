# 10 図形のみで表す室内家具・設備（プレビュー）

状態: **表示形式の設計案**。図形プレビューは作成済み。現行マップ編集画面へのプリセット配置は未実装。

## 目的・表示ルール

- **アイコンが適切でない対象を、図形のみで表示する。** 例：机・棚・ベッド・大型機械・タンク。
- 物資は、原則 [09 室内物資アイコン対応表](09-indoor-supply-icon-catalog.md) に登録した**文字アイコン**で識別する。30種類すべてに簡易矩形・円を重ねることを必須としない。
- 両方の表示が必要な特殊なケースのみ、後からアイコンと図形の併用を選択可能にする。
- 図形は部屋を上から見た**平面図**として制作し、名前だけの一覧ではなく**実際に描画した図形プレビュー一覧**で確認できるようにする。

## 実際の図形を閲覧する

[室内図形一覧（SVGプレビュー）](../../rebuild/shape-catalog.html)

アプリでは「☰ マップ → 📖 仕様書を見る → **10 図形プレビュー**」から、画面内で13種類の図形を一覧表示できる設計。

## データと操作への要件

- IDで図形プリセットを選び、位置・サイズ・角度・階・部屋を指定して配置する。
- 実際の編集で使う図形定義はプレビューと同じデータを参照し、二重管理を避ける。
- プレビュー中に図形の輪郭がわかり、文字アイコンと混同しない。
- 図形の外観と実際の当たり判定・通行障害の有無は別属性として保存する。
