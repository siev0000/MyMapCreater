## 分類規則

- 世界観：`machine` → 画面では「機械」
- 所属階層タグ：`tags: ["中層"]` → 画面では「中層」
- 既存の分類：`category: "machine_midlayer"` → メインの施設選択では「機械｜中層」
- テンプレートプレビューの「階層タグ」で中層を選ぶか、一覧上部の「中層」ボタンで絞り込む
- タグと世界観は別の条件として扱う。現代日本の住宅に中層タグを付けない
- 「別名保存」したカスタムテンプレートは中層タグを引き継ぐ

## 中層マップの既存配置を復元：ギルド複合区《レジストリンク・ドーム》

- **確認元**：GitHub `rebuild/scenes/middle.scene.json` の `middle_terminal` と `resist_link_dome`、2026-11-11確認。
- 中層ターミナル：中心 `[0,0]`、円形半径250m（直径500m）。
- レジストリンク・ドーム：`middle_terminal` の**子区画**。同心の円環、**内半径130m・外半径210m**。独立した外部の四角い建物ではない。
- ターミナル中央は一般・大型機のリフト乗降区。円環に8か所の受付を設け、その近傍に小作戦室を併設する初期案。
- 船首・船尾（±X）は大型機専用通路、左右舷（±Y）は一般出入口として中層マップで仮設定。詳細接続は後続の中層再制作時に検証。
- テンプレート生成器 `generateRegistlinkDome` は**円形ターミナル＋円環ギルド**を一体出力する。室の小分け、エレベーター群の相対位置、扉の幅は仮案。
- テンプレートの `cells:[1000,1000]` は直径500mを50cm/マスで表す**透明の編集用外接矩形**。外形として矩形の建物を表示する意図はない。
- この修正で現行の `middle.scene.json` 自体は変更していない。GitHubで確かめた仮配置にテンプレートのほうを揃えた。
- **Notionとの不一致**：Notionの「エリア」ページの旧配置表に `[1050,0]`・650×600mの「独立ドーム」と読める項目が残っている。一方現行GitHubシーンでは上記の中央ターミナル内円環。正本への追記・旧配置表と経路の整合確認を別途必要とする。
- `レジストリンク・ドーム`の施設機能（受付、任務、報酬、会議、倉庫、アルキメリア、バイオノーム）は[Notionの施設ページ](https://app.notion.com/p/1defa1b30dc9808f857ccbc8f17ef5b9)から変更しない。

### リフト・接続・壁・扉

- 中央の乗降ホールとリフト本体を分離。一般シャフト4基は各8×10m（16×20マス）、大型機用シャフト2基は各12×16m（24×32マス）。個数も寸法も仮。
- 半径130～146mの内側公共コンコースは幅16m（32マス）。半径174～182mの業務連絡環状通路は幅8m（16マス）。半径204～210mの外周保守帯は幅6m（12マス）。
- 中央リフト側から4本の軸通路。船首・船尾の大型機通路は**有効幅12m・高さ8m**、左右舷の一般通路は**有効幅8m・高さ7m**。内周・外周・中央塔外殻の開口は同じ実寸幅で計算する。
- 受付と一般室扉は原則**幅6m・高さ6m以上**、大型待機や共用受付は幅8m・高さ7m、倉庫・密閉保管は幅10m・高さ8m（必要に応じて個別設定）。部屋前に実体を持つ通路接続ポリゴンを作る。
- 中央ターミナル外殻の壁厚100cm（2マス）、ドーム円環の内外周壁60cm（1.2マス）、通常間仕切り25cm（0.5マス）、管理・倉庫区画35cm（0.7マス）、危険物・生物用の隔離室壁100cm（2マス）。**構造安全を証明する数値ではない**。
- 部屋65室・警備認証4か所に、出入口と接続通路を配置した。機体の最大横幅・旋回半径・実際のエレベーター能力は未設定であり、通行可能性の最終確認が必要。

**仕様状態**：GitHubの制作用テンプレートへ反映済み／Notionは機能名称・組織・役割の正本。正式な階数、警備配備数、室数、具体的な位置は今後の調整対象。旧Notion「エリア」表の別棟座標との不一致は引き続き保留。
