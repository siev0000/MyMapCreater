## 分類規則

- 世界観：`machine` → 画面では「機械」
- 所属階層タグ：`tags: ["中層"]` → 画面では「中層」
- 既存の分類：`category: "machine_midlayer"` → メインの施設選択では「機械｜中層」
- テンプレートプレビューの「階層タグ」で中層を選ぶか、一覧上部の「中層」ボタンで絞り込む
- タグと世界観は別の条件として扱う。現代日本の住宅に中層タグを付けない
- 「別名保存」したカスタムテンプレートは中層タグを引き継ぐ

## 新規追加：ギルド複合区《レジストリンク・ドーム》

- 施設名・用途：**現行Notionに基づく**
- 48×36m、1階構成、区画数・区画位置：**ゲームマップ編集用の仮案**
- 仮の内部ゾーン：共通任務受付・検索区、作戦会議区、個別通信ブース区、ストレージゾーン、アルキメリア区画、バイオノーム区画、共用通路
- 任務ランクの正式名称・段階など未確定事項は新規に補完していない
- 外周壁・区画壁には既存のサイズ別壁厚目安を適用
- 配置物、扉、室区分は再制作時に編集・削除できる
- **ドーム外観や屋根形状も未確定**。平面配置は四角い編集用枠で、最終的なドーム形状を主張するものではない

## 新規追加：兵器場（中層仮施設）

- 新規テンプレートID：`machine_mid_weapons_yard`、タグ：`中層`、世界観：`machine`、用途：`production`
- **「兵器場」という独立施設・正式名称・所在地・寸法は現行Notionに確定記載がない**。ユーザーの要望に応じた編集用の施設試案として扱う。
- サイズ：40×30m、1階（**仮**）。外周壁40cm／内部区画壁25cmは既存のマップ制作向け壁厚目安。
- 仮の区画：部品受入・検品、武装組立、加工・調整、完成兵器保管、試験・安全検査、整備・制御、および中央搬送・通行路。
- 中央に搬送路を通し、各区画へ独立した引き戸を設ける。南北に搬入口を設けた試作平面図。部屋数・接続・設備の配置はNotionで確定していない。
- 既存の「武器製造・改造工房」（16×12m・小型）とは区別する。兵器場は仮に製造・保管・検査を集約する大型施設として設計した。
- 新規兵器場を実際に中層マップへ配置する作業は未着手。後続作業で所属地区・搬入出経路・設置場所を確認する。
