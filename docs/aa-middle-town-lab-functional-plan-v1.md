# AA中層｜タウン・ラボの機能整理 v1

> 作業段階：主要街区の機能整理。**部屋の数・住民数・街区内小道・新規建物の座標は未確定**。GitHub中層下書きで役割を整理し、Notion正本への書き込みは行わない。

## 1. 区分の考え方

中層の生活・整備圏《コアシェル・リファイン》は、リンクターミナルを基点とする生活と技術の連続した地区。

| 位置・区分 | 対象ID | 位置づけ | 主な機能 |
|---|---|---|---|
| 船首・上位タウン | `core_shell_town` | 生活地区 | 休止・補給、商業、交流、日常点検 |
| 船首・上位ラボ区 | `refine_valley` | 技術・整備地区 | 修理・診断、装備強化、個人工房群、アルキメリア装備開発ラボ |
| 船尾・下位タウン | `stern_core_shell_town` | 生活・生産の混合街区 | 休止・補給、市場、一般生活、小工房、燃料・油加工施設と近接 |
| 船尾・下位ラボ区 | `stern_refine_lab_district` | 技術・生産の混合街区 | 修理・試験、実用技術ラボ、繊維樹脂・資源加工施設と近接 |

上位・下位の意味はユーザー指定の**船首側／船尾側の社会的な地区区分**。具体的な居住資格・通行制限・設備水準・価格差は設定されていないため追加しない。

**地区の外形は一棟の建物ではない。** 船尾の半円の街区は、住宅・工房・ラボ・工場の個別施設、一般街路、広場、貨物専用路を内包する。先に決めた加工施設4棟の小型寸法はそのまま。

## 2. タウンの機能（船首・船尾の両方）

1. **住居・休止系**：個体用休止室、停止保管、共同充電・燃料補給、冷却。
2. **生活補給**：水・空気・交換消耗品の供給、洗浄・除塵・簡易診断。
3. **市場・商業**：生活物資、中古部品・工具の販売、サービス窓口。
4. **交流・情報**：固定掲示板、情報交換、共有ラウンジ、娯楽。

タウン内で許容するのは軽整備まで。本格的なフレーム修理、危険な機体改造、汚染除去はラボ・工房側の専門設備に送る。

### 利用導線の配置原則
- **ターミナルに近い側**：一般入口・案内・市場・補給。
- **一般通路の奥側**：休止設備・住宅など、騒音が少ない機能。
- **整備・工房と接する側**：軽点検・部品販売・修理受付。
- 紫の大型機専用通路や橙の工業貨物専用路を住民通路として使用しない。

## 3. ラボ・工房地区の機能（船首・船尾）

1. **整備・診断**：機体損傷、外装、動力・内部回路の診断、洗浄・除染。
2. **装備改修**：武器、外装、補助装備の修理、強化、カスタム改造。
3. **個別開発**：持ち込み装備の調整、試作、素材検査、個人・少人数の小工房。
4. **工具・部品**：修復材、工具、交換部品の倉庫。燃料・危険物は分離保管。

**船首側：** リファインバレーの既存アルキメリア装備開発ラボ（`alchimeria_lab`）を含む。個人工房群（セルリンク、ケランク、ボルスコなど）はNotion上ではリファインバレー内に点在する設定であり、個別の座標・棟数は未設定。

**船尾側：** GitHub案として追加している実用技術ラボ（`stern_equipment_lab`）。実用修理・素材加工連携を想定するが、**現時点でNotionの正式施設ではない**。船尾に個人工房群を追加するかどうかも未確定で、既存のリファインバレーの個人工房群が自動移設されたわけではない。

### 利用導線の配置原則
- **一般街路側**：受付、診断・相談、軽整備窓口。
- **技術地区の奥側**：整備・試作・本格改修、必要な隔壁・空調。
- **工業貨物路側**：素材受入れ、交換部品倉庫、工場との材料引渡し。
- **個人工房**：共同用資源・試験設備へアクセスできること。全工房を巨大な単一工場として描かない。

## 4. タウン・ラボ・ギルドの違い

| 主目的 | 施設 |
|---|---|
| 居住・休止・商業・生活補給 | タウン |
| 機体診断・修理・装備開発・個人工房 | ラボ・工房地区（リファインバレー等） |
| 任務受付・報酬・会議・共通倉庫・ギルド案内 | リンクターミナル内の《レジストリンク・ドーム》 |
| 燃料・植物油・繊維樹脂・植物資源の製造 | タウン・ラボ街区に混在する4つの独立した加工施設 |

アルキメリア**ギルド窓口**はレジストリンク・ドーム側、**装備開発ラボ**はリファインバレー側として区別する。
