# 中層中央部｜リンクターミナル内レジストリンク・ドーム v2

> **GitHub表示・配置検討案。Notion正本は未変更。**
>
> この文書は、前案 `aa-middle-central-replan-v1.md` の **ターミナル外部（半径335～425m）にドームを置く方式を置き換える**。

## ユーザー決定の方向
- リンクターミナル内にレジストリンク・ドームを設ける。
- ターミナルからどの方向にも受付しやすいよう、受付を円周上に分散配置する。
- 各受付に隣接して小さな作戦室を置く。
- 大型機がターミナル内から外へ通過できる通路を設け、一般通路と隔壁・シャッターで区分する。
- タウン、リファインバレー、アルキメリア装備開発ラボは近接する同一都市生活圏。ラボはバレー内に属する。

## 中層中央部の暫定寸法
| 中心からの半径 | 機能 |
| --- | --- |
| 0～100m | 一般・大型機リフト、乗降・交通中枢 |
| 100～130m | 乗降ホールの待機・認証・検査・案内 |
| **130～210m** | **レジストリンク・ドーム環状ギルド施設** |
| 210～250m | ターミナル外周出口・非常動線 |
| 250～330m | 既存構想のターミナルコンコース（塔の外側） |
| 330m以遠 | タウン・工房街等の生活圏 |

- 中央塔直径500mは**三層共通の暫定寸法を維持**する。
- 環状ドーム内で8組の受付を設け、それぞれに小作戦室を複数併設。
- 船首・船尾方向に48mの大型機専用通路を2本、左右舷方向に24mの一般通路を2本。
- 大型機通路に面したギルド区画はシャッターで隔離し、許可されない通り抜けを認めない。
- 分隊本部、大会議、ストレージ、アルキメリア・バイオノーム窓口は環状受付の中にある管理室群。
- 詳細な区画・扉・柱の設計は**仮表示**であり、通行網の全線接続・避難基準・構造計算は未確定。

## 実装ファイル
- `data/middle-layout-draft.json`：中央塔の内部区分、ドームの環状半径、8受付、内部室、ゲートと通路。
- `middle-central-ring.js`：環状ギルド施設、乗降ホール、受付、各小作戦室、大型機・一般通路の描画。
- `index.html`：ギルドをターミナルの**内側で描画**し、選択リストにもターミナルの配下として表示。
- `editor.html`：同じドーム描画処理を使用。中層ターミナルを円形表示。
- `data/middle.json`：**Notion初期配置の比較用データ。変更しない。**
