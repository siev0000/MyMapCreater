## 全階層に共通して維持する基礎
- 船体長4,000m、最大幅2,500m。
- 船首：X正、船尾：X負、右舷：Y正、左舷：Y負。
- 上層・中層・下層ターミナルは全て `(0,0)`、共通中央塔の直径500mを**暫定維持**。コンコースは半径250～330m。
- 三層の一般用リフトは各階ターミナルに停車。貨物用、危険物用、外征直通、非常用は用途を分ける。
- 船殻外周の推進・保守系は、一般の交通・生活地区と直接接続しない。
- **地区**は生活・研究・工業等の領域で、**建物1棟**とは区別する。
- 下層船首の上層専用出撃区の境界 `X≥700m` は**GitHub配置案のみ**の提案であり、Notionの確定隔壁位置ではない。

### 中層の最優先問題：アルボラと工業群の重なり

GitHub案：アルボラ `(-1040,0)`、寸法 `1050×1300m`。
Notion初期配置：`(-150,900)`、寸法 `1500×500m`。

このGitHub案のアルボラ矩形は、下記4施設の**現在の矩形占有範囲と重なる**（図面の簡易矩形モデル。正確な隔壁形状や立体的な重なりを確定したものではない）。

| 相手の施設 | 簡易矩形重複寸法 |
| --- | --- |
| 標準燃料生産施設 | 約495×310m |
| 植物油加工区 | 約400×260m |
| 植物繊維・樹脂加工区 | 約400×260m |
| 植物資源加工施設 | 約450×260m |

**先に決めること**：アルボラと工業加工群をどこで分けるか。自然区を船尾中央に置く案を維持するのか、Notion初期の右舷寄り案へ寄せるのか、または双方の外形を再設定するのか。**答えが決まるまで、小区画・工房・温室の詳細座標は固定しない。**

中層中央の希望として決まっている関係：
- レジストリンク・ドームは**リンクターミナル内部**（GitHub案半径130～210m）。
- コアシェルタウンとリファインバレーは同じ連続した生活圏。
- アルキメリア装備開発ラボはリファインバレー内部。
- 通常の街区が300～600m程度でも、一棟の建物を300～600mにする意味ではない。
- 武装運用区はGitHub案の `middle_weapon_operation_field` にだけあるため、未承認施設として扱う。

### 下層の優先問題：搬入・隔離と船首出撃区

| 対象 | Notion初期位置 | GitHub配置案 |
| --- | --- | --- |
| リクレイムベルト | `(-950,0)` | `(-800,-500)` |
| アシッドゾーンS9 | `(-1250,-600)` | `(-1120,510)` |
| バイオリアクター | `(-950,800)` | `(-1040,0)` |
| マテリアル・ホロー | `(1050,-650)` | `(240,-540)` |

Notion初期案のマテリアル・ホローは `X=1050` であり、GitHub側で検討中の**上層専用出撃区（X≥700）と位置が競合する**。両方を現在の座標・隔離ルールで正式採用することはできないため、**下層の一般・外部搬入口の位置と出撃区隔壁のどちらか、または双方の案を見直す必要がある**。移動先はまだ確定しない。

ラストハブを中央の生活圏として保ち、危険区の経路を一般ターミナルの通路に直結させない。

1. 上層「中央共有・M研究・E研究」の大区分と認証位置の方向性。
2. 中層「中央生活圏・アルボラ・燃料素材加工区」の非重複の置き方。

4. 中央塔の共通位置・暫定寸法、一般／大型機／貨物／危険物の分離方針。
