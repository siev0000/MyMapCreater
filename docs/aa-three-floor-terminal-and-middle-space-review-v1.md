# AA三階層ターミナル統一・中層余裕領域整理（GitHub案）

> 状態：**HTML表示・GitHub配置案**。世界設定正本のNotionは変更しない。
>
> この作業の根拠：Notion「エリア」の中央ターミナル初期半径250mとコンコース250～330m、各階層設定。前の中層ターミナル内ギルド修正は保持。

## 共通の中央ターミナル
- すべての階層で中央 `(0,0)`、直径500mを暫定維持。
- 中央半径0～100m：一般・大型機リフトと乗降。
- 半径100～130m：待機・認証／簡易検査・案内（階層に応じて運用差分）。
- 半径130～210m：各階層に必要な機能区画。
- 半径210～250m：出口・連絡通路・避難動線。
- 半径250～330m：既存Notionの外周コンコース。**内部区画で代替しない**。
- 一般通路と大型機用を分けた出口を描画。幅24m（一般）・48m（大型機）は**検討用の開口**で、認証・ゲートと外部道路接続は未確定。

## 上層の内部機能（仮区画）
- 案内・共同受付
- 認証・保安検査
- 応急・避難支援
- 外征リフトの連絡案内

研究区へのマギテック／エイドロン認証門は**ターミナル内へ移動しない**。既存GitHub上層の認証門と通路の位置ずれは別件の未解決問題。外征直通リフトの駅位置も本メモでは確定しない。

## 中層の内部機能
- ターミナル内部の `resist_link_dome` は**半径130～210m**。
- 環状8受付、小作戦室、分隊本部・大会議・ストレージ・アルキメリア・バイオノーム窓口。
- 外部の生活圏はコアシェルタウン・リファインバレー・アルキメリア装備開発ラボが同じ市街地に近接。ドームを別都市として配置しない。

## 下層の内部機能（仮区画）
- 一般案内・受付
- 認証・簡易検査
- 応急修理・充電
- 避難・緊急対応

中央ターミナルからラストハブへの連絡を重視し、再処理区・危険区・有機廃棄物・資源搬入の**貨物専用・隔離経路を一般通路に混在させない**。下層の船首側（X+700mから）は上層専用出撃区のまま。

## 中層の空き領域の整理（未割当と空き地を区別）

現在JSONに表示される建物・道路が少ない地域でも、それを建設できる空き地とは判定しない。

| 類型 | 主な既存要素 | 方針 |
| --- | --- | --- |
| 生活・商業・工房の街区 | コアシェルタウン、リファインバレー、アルキメリアラボ | 同じ連続した生活圏を保持 |
| 公共交通・大型機移動 | ターミナル、中央環状路、輸送ポッド環状線、任務大通り | 交通・ゲートを優先して調整 |
| 環境・栽培 | アルボラ、温室、水・土壌循環 | 特有の天井雨・空調・生態環境を分離 |
| 工業・物流 | 燃料加工、繊維・樹脂、貨物検査 | 一般道路と重貨物・危険物経路を分ける |
| 構造設備・未割当 | 支柱、壁、配管、非常通路、保留用地など | 未登録のまま維持、配置条件が確定するまで建築しない |

### 未解決課題
1. 中層の街区・幹線道路・アルボラ・工業物流を実際につなぐ区間はまだ未検証。
2. 上層マギテック・エイドロン認証門と通路の位置ずれは既知の未解決。
3. 下層は専用出撃区の隔壁と、生活区・危険区の通行権限の独立性を継続確認。
4. 街区内の空きが十分かどうかは、防火・環境隔壁、構造柱、搬送幅を決めてから検証する。
