# リンクターミナル・レジストリンク・ドーム｜テンプレート制作・接続設計ルール
更新日：2026-11-12
状態：確定要件と試作実装を分離して管理

## 確定要件（ユーザー指示）
- まず建物テンプレートを作成・編集し、完成後に中層シーンへ追加する。中層シーンに先行して内部オブジェクトを直書きしない。
- 直径500mの既存中央ターミナル外形を維持する。
- 中央構造柱の周囲に左上・右上・左下・右下の4群の昇降機を配置。各群に一般用1基・大型用1基、計8基。
- リンクターミナルは昇降機から到着した個体向けで、昇降機側を向いた案内・受付。
- レジストリンク・ドームは外側から到着した個体向けで、外周側を向いた広めの分散受付。非常に多数の来訪を想定。
- 施設間の連絡通路のみ通行許可制。警備担当個体は通行可。通常の施設入口にこの施設間許可を要求しない。
- 一般個体用と大型機・貨物用の通路を分ける。
- 昇降機本体から実際に扉を通って移動できる構造を設計する。

## 実装時の必須手順
1. **新規**テンプレート `machine_mid_link_terminal_dome_v2` を編集し、専用の編集プレビューで確認する。**旧試作** `machine_mid_registlink_dome` は参照用に保持し、明示許可なしに変更しない。
2. 昇降機ごとに「昇降路（シャフト）→実際の開口部・扉→乗降ホール→通路→案内・受付／倉庫」をつなぐ。扉は単なる線の装飾にせず、通行可能な開口と対応づける。
3. 一般用・大型貨物用の扉幅、必要通路幅、壁と開口の関係をそれぞれ設計し、通路同士が不用意に交差しないようにする。
4. 壁は開口位置で分割する。壁を横断する通路、壁の内側に閉じ込められた部屋、扉のない昇降機を残さない。
5. レジストリンク・ドームの外周側入口→分散受付→待機・任務管理区画の経路を確保する。受付の正面を内側に向けない。
6. リンクターミナルとドームの施設間連絡部には許可確認を設ける。警備通行権限を区別する。通常入口は自由利用とする。
7. 部屋・倉庫・会議室・検査・危険物隔離の各経路を確認する。貨物／大型機経路と一般個体経路を混在させない。
8. 最終確認：全昇降機から通路へ到達可能か、全受付へ外周から到達可能か、全施設間経路が認証部を通るか、各部屋に扉があるか、閉塞・重複・衝突がないかをテストする。
9. **通行可能性をコードとプレビューで確認できるまで完成扱いにしない**。確認後にテンプレートから中層へ配置する。
